Computer System Security Audit

An automated, strictly read-only security audit of a live Windows 11 workstation. The audit engine inspected the host operating system across five defensive domains, evaluated 31 deterministic security checks, calculated a 100-point security score, and recorded OS evidence with exact remediation commands for every finding.

1 · The project

The project in one minute

The task

Audit a computer's actual security posture

Query accounts, hotfixes, NTFS ACLs, background services, and defensive configurations against CIS benchmarks.

Where

A controlled, read-only local lab

Everything ran on my own Windows 11 laptop on 127.0.0.1. No remote hosts or write actions were touched.

The output

Actionable evidence & exact fixes

31 checks scored out of 100, backed by raw OS telemetry, an interactive dashboard, and a formal PDF report.

Key terms

Security Audit

A systematic check that compares a computer's active settings against established security benchmarks (such as CIS Windows 11 and NIST SP 800-115).

NTFS ACL

The access control list attached to every file and folder that specifies which users or groups can read, modify, or execute it.

LocalSystem Privileges

The highest internal authority in Windows (NT AUTHORITY\System). Services running as LocalSystem have kernel-level control over the operating system.

2 · Background

Why computer system security auditing matters

Background

Most cybersecurity incidents do not begin with exotic zero-day exploits; they exploit silent configuration drift. Over months of normal use, software installers register background services with excessive rights, local accounts are created with blank passwords, and security updates stall unnoticed.

Microsoft ships Windows with strong defenses (Defender Antivirus, Windows Firewall, and UAC), but a single misconfigured service or weak password policy can completely undermine those protections once an attacker gains initial foothold.

Problem statement

Manual host auditing is slow and fragmented. An administrator must check lusrmgr.msc for accounts, net accounts for policies, services.msc for daemon paths, icacls.exe for file permissions, and Registry keys for OS hardening.

Students and security professionals need a safe, deterministic, and repeatable audit tool that inspects all five domains automatically without risking harm to the operating system.

Fix the misconfiguration before an adversary exploits it. That is the purpose of host security auditing.

3 · Aim

Aim and objectives

Main aimDesign, implement, and validate an automated read-only Computer System Security Audit system on a live Windows workstation across five core defensive domains.

  1. User Accounts (20 pts)

    Verify built-in accounts, password requirement flags, and system-wide password length and lockout policies.

  2. System Updates (20 pts)

    Inspect Windows build currency, installed KB hotfixes, days elapsed since latest patch, and update services.

  3. File & Folder Permissions (20 pts)

    Parse NTFS ACLs on System32, hosts file, Program Files, and StartUp folders for unprivileged write rights.

  4. Running Services (15 pts)

    Detect unquoted service binary paths (CWE-428), legacy services, and third-party binaries running as LocalSystem.

  5. Security Configurations (25 pts)

    Audit Windows Defender, 3 Firewall profiles, UAC Secure Desktop, UEFI Secure Boot, SMBv1, and BitLocker.

4 · Scope

Scope: a controlled, read-only laboratory

All testing was strictly confined to the local loopback boundary (127.0.0.1) on my Windows 11 workstation.

5 · Target

The target: Windows 11 Workstation

A real-world Windows 11 environment running standard productivity, developer, and gaming software.

  1. Live Host Telemetry. Evaluated against real local accounts, active background services, and real NTFS security descriptors.
  2. Safe and Non-Destructive. Command safety filters prevent accidental modifications during scanning.
  3. Standard-Compliant. Benchmark criteria derived from CIS Microsoft Windows 11 Benchmark v3.0.0 and NIST SP 800-115.
In plain words

WinSecAudit provides an objective security score out of 100. It highlights that even when Windows Defender and Firewall are running perfectly, third-party software and permissive password policies can introduce critical privilege escalation risks.
