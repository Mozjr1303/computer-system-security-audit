F1

Active Local Administrator Account Has PasswordRequired = False

Critical Confirmed Vulnerability Found by: User Accounts AuditorCheck: USR-004Source: SAM / Get-LocalUser

The primary local account holding membership in BUILTIN\Administrators has its account attribute PasswordRequired set to False. The account can be signed into or elevated without a password barrier.

In plain words

Passwordless Admin: The most powerful account on the machine is configured so Windows does not insist on a password. Anyone sitting at the keyboard can gain administrator privileges without authentication.

Potential impact

  • Allows immediate privilege escalation or local sign-in without credential guessing
  • Completely circumvents User Account Control (UAC) credential dialogs

Recommended fix

  • Enforce password requirement: net user "<Username>" * /PASSWORDREQ:YES
  • Assign a strong passphrase of 14+ characters immediately
F2

Unquoted Service Binary Path in UpcElevationService (CWE-428)

High Confirmed Vulnerability Found by: Running Services AuditorCheck: SVC-001Service: UpcElevationService (LocalSystem)

UpcElevationService (Ubisoft Connect Elevation Service) runs as LocalSystem, but its registered executable path contains spaces and is not enclosed in double quotes: C:\Program Files (x86)\Ubisoft\Ubisoft Game Launcher Core\UpcElevationService.exe.

In plain words

CWE-428: Because the path has spaces and no quotes, Windows tries to run C:\Program.exe and C:\Program Files (x86)\Ubisoft\Ubisoft.exe before finding the real program. An attacker who drops a file there gains full LocalSystem control.

Potential impact

  • Local privilege escalation to NT AUTHORITY\System (highest OS privileges)
  • Persistent execution whenever the Ubisoft elevation service is triggered

Recommended fix

  • Wrap the service executable path in double quotation marks in the Windows Registry:
Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Services\UpcElevationService" -Name "ImagePath" -Value '"C:\Program Files (x86)\Ubisoft\Ubisoft Game Launcher Core\UpcElevationService.exe"'
F3

System Minimum Password Length Policy Set to 0 Characters

High Security Weakness Found by: User Accounts AuditorCheck: USR-006Source: net accounts

The workstation's local account policy specifies a minimum password length of 0 characters. Users can change their passwords to empty strings or single characters without Windows enforcing any minimum threshold.

In plain words

Zero-Length Passwords: CIS benchmarks recommend requiring at least 8 to 14 characters. Setting this to 0 allows blank passwords and facilitates brute-force attacks.

Potential impact

  • Enables creation of blank or single-character passwords
  • Directly facilitates Finding F1 (passwordless local administrator account)

Recommended fix

  • Enforce a minimum length of 12 or 14 characters: net accounts /minpwlen:12
F4

14 Third-Party Services Running as LocalSystem Outside C:\Windows

Medium Security Weakness Found by: Running Services AuditorCheck: SVC-005136 Running Services Analyzed

Out of 136 running services, 89 run as LocalSystem. 14 of those belong to third-party vendor utilities (such as ASUS Armoury Crate, Dolby DAX, Huawei PC Manager, and Zapret) rather than core Windows OS components.

In plain words

Least Privilege Violation: Background apps for laptop lights and audio drivers have the same kernel-level rights as the Windows operating system itself.

Potential impact

  • Expands the blast radius: a vulnerability in any vendor software grants full system compromise

Recommended fix

  • Uninstall unused vendor bloatware and downgrade non-essential service logon accounts
F5

Windows Print Spooler (spoolsv.exe) Running as LocalSystem

Low Configuration Observation Found by: Running Services AuditorCheck: SVC-004Binary: spoolsv.exe

The Windows Print Spooler service is running automatically as LocalSystem. If the workstation does not require physical document printing, running the spooler exposes legacy RPC endpoints unnecessarily (PrintNightmare attack surface).

Recommended fix

Disable the spooler if not actively printing: Stop-Service Spooler; Set-Service Spooler -StartupType Disabled

F6

Privilege Boundary: BitLocker & Temp Folder (Not Assessed Under Standard User)

Info Elevation Gated Checks: SEC-008 & PERM-005Excluded from scoring denominator

Right-click start_audit_system.bat and select "Run as administrator".

Impact

How the weaknesses connect

Chaining isolated configuration gaps into complete host takeover.

  1. Step 1 · Zero-Length Password Policy (F3)

    The system allows blank or trivial passwords, facilitating passwordless account persistence.

  2. Step 2 · Passwordless Admin Account (F1)

    Active administrator account requires no password, allowing local logon or elevation without credentials.

  3. Step 3 · Unquoted Service Path (F2)

    Ubisoft elevation service has unquoted path with spaces, vulnerable to executable planting in parent folder.

  4. Step 4 · Kernel-Level Execution (F4)

    Execution as NT AUTHORITY\System grants persistent, total control over the Windows operating system.

Conclusion

Conclusion: turning raw settings into clear security answers

This audit proves that even when Windows Defender, the Firewall, and Secure Boot are fully operational, third-party installers and human account policies can still leave severe privilege escalation doors open.

By automating 31 checks across five core domains, WinSecAudit detected these weaknesses in under four seconds and provided the exact commands needed to raise the workstation's posture score from 86.0 / 100 to 97.0+ / 100.
